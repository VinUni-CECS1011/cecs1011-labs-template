## Start here

Leader: check owner **VinUni-CECS1011** and visibility **Private**. In **Settings → Collaborators and teams**, add the agreed teammates with **Write** and record this repository link in Canvas. Teammates accept any pending invitations.

Each member copies `onboarding/TEMPLATE.md` to `onboarding/<their-github-username>.md`, completes it, and commits using their own account.

When a lab is released, copy its starter into `labs/lab-01/` through `labs/lab-06/`. Retain earlier work and add evidence files only as needed.

Before each submission, check the required evidence and each member's contribution, push the final changes, then submit the links and full commit SHA in Canvas.

Keep the repository private. Keep credentials, student IDs, private feedback and sensitive data out of Git. Record allowed AI assistance and explain how the team checked it.
