## Start here

Team representative: check owner **VinUni-CECS1011** and visibility **Private**. In **Settings → Collaborators and teams**, add the agreed teammates with **Write** and record this repository link in Canvas. Teammates accept any pending invitations.

Each member copies `onboarding/TEMPLATE.md` to `onboarding/<their-github-username>.md`, completes it, and commits using their own account.

**Lab 1:** edit the report already in `labs/lab-01/README.md`; add your evidence in `labs/lab-01/evidence/`. Follow [Lab 1, Step 4](https://vinuni-cecs1011.github.io/labs/lab-01.html#prepare-report) to edit it or add it if missing. Keep your existing work. Lab 1 needs one shared report and contribution table, without separate individual reflection files or PDFs. You can complete it in a browser.

**Lab 2:** follow the [Lab 2 handout](https://vinuni-cecs1011.github.io/labs/lab-02.html) and use `labs/lab-02/README.md` for the shared report. Each member completes the introductory CAD practice individually; the team begins its own design in class and completes it afterward. Save one representative practice image and file, a dimensioned starting sketch, and a final-model image with the design's native document and STL. If the folder is missing, follow the handout's steps to create `lab-02` inside `labs` and add its report. Updated templates do not change existing repositories automatically.

When Labs 3–6 are released, add their starters to the corresponding folders. Retain earlier work.

Before each submission, check the required evidence and each member's contribution. Save with **Commit changes** on GitHub (or `git push` if working locally), then submit the team name, ordinary repository link, report file path and latest full commit SHA in Canvas before its deadline. No permanent link is required. Saving on GitHub does not submit the Canvas assignment; follow Canvas for permitted resubmissions.

Team numbers may repeat across sections. For a repository not yet created, include both section and team identifiers in its name, for example `f26-cecs1011-secSECTION-teamTEAM-labs`. Keep using an existing repository and preserve Lab 1; a rename is not required to add Lab 2.

Keep the repository private. Keep credentials, student IDs, private feedback and sensitive data out of Git. Record allowed AI assistance and explain how the team checked it.
